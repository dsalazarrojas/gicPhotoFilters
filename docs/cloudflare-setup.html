BYOK

Use your Cloudflare key on gicPhotoFilters

gicPhotoFilters now lets you plug in your Cloudflare account ID and Workers AI token so transforms run directly from your browser. These credentials stay in sessionStorage and never hit GIC's backend.

1. Create a Cloudflare account

Head to dash.cloudflare.com/sign-up and follow the onboarding flow. Cloudflare's free tier includes Workers AI credits.

2. Find your Account ID

From the dashboard, open “Account Home” and copy the Account ID from the right sidebar. This value is required in the Try page BYOK panel.

3. Create a Workers AI token

Under “My Profile → API Tokens”, create a scoped token with Workers AI: Run permission. Paste it into the BYOK panel. The token stays in your browser tab only.

Live mode

What happens after you enter credentials

Once the BYOK panel is configured, the Try page calls Cloudflare's REST API directly for every supported filter. No data goes through GIC's backend, so your billing and neuron usage stay with Cloudflare.

  • The browser POSTs to https://api.cloudflare.com/client/v4/accounts/{Account ID}/ai/run/{modelId} using your token.
  • A single transform returns an image blob that the page renders instantly and can download or share.
  • Credentials are stored in sessionStorage only, cleared when the tab closes. GIC never receives or logs them.
Session view

Quick tips for the BYOK workflow

Use the “Use your own Cloudflare API key” panel on the Try page. Toggle between demo and live mode, paste your Account ID + token, and watch the live status badges update.

  • The live mode toggle keeps demo-only preview examples available until you enter both credentials.
  • Live transforms increment a session neuron counter shown beside the panel so you can track how much you are spending.
  • When live mode is active the “Share result” button shares the actual output image; “Share filter” still copies the Try page link.
