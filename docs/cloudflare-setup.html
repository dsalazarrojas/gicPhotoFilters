Use your Cloudflare key on gicPhotoFilters

gicPhotoFilters now lets you plug in your Cloudflare account ID and Workers AI token so the site can securely proxy transforms on your behalf. These credentials stay in your browser storage choice and are forwarded only as HTTPS request headers to /api/health and /api/transform.

1. Create a Cloudflare account

Head to dash.cloudflare.com/sign-up and follow the onboarding flow. Cloudflare's free tier includes Workers AI credits.

2. Find your Account ID

From the dashboard, open “Account Home” and copy the Account ID from the right sidebar. This value is required in the Try page BYOK panel.

3. Create a Workers AI token

Under “My Profile → API Tokens”, create a scoped token with Workers AI: Run permission. Paste it into the Settings modal. You can store it in this browser or keep it session-only.

What happens after you enter credentials

Once Settings is configured, the website always posts to /api/transform. That endpoint securely forwards your Cloudflare credentials in request headers, so your billing and neuron usage still stay with Cloudflare without exposing the token in URLs.

  • The browser POSTs to /api/transform; the worker attaches X-CF-Account-ID and X-CF-API-Token to the upstream Cloudflare call.
  • A single transform returns an image blob or stored result URL that the page renders instantly and can download or share.
  • Credentials are stored in your chosen browser storage and are never written to server-side logs or databases.

Quick tips for the BYOK workflow

Use the Settings gear from the header or the Try/Build page status banners. The setup wizard opens as a modal so your photo, builder prompt, and page scroll position all stay intact underneath.

  • The Try page keeps demo examples available until you enter both credentials and test the connection.
  • BYOK runs increment a browser-side session neuron counter so you can track how much you are spending.
  • The Build page can open the setup wizard or settings modal without clearing your prompt, uploaded photo, or test results.
